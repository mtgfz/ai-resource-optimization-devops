# Contributing

1. Never push directly to `main`.
2. One branch per task: `feature/<pillar>-<short-name>` (e.g. `feature/monitoring-dashboard`).
3. Small commits with clear messages: `feat:`, `fix:`, `docs:`, `chore:`, `test:`.
4. Open a Pull Request (PR) and ask a teammate (not yourself) to review it.
5. Keep generated data out of PRs, except raw experiment results in `experiments/results/`.
6. Report/guide text is written by hand by each owner (course rule: no AI in final deliverables).
