# Report outline (research-paper style, English, IEEE refs)

Title / Abstract (150-250 words) / 4-6 Keywords
1. Introduction  2. Related Work  3. Problem Statement and RQs
4. Proposed Architecture and Methodology
5. Implementation and Experimental Setup (hardware, software versions, workloads)
6. Results and Evaluation (tables, graphs, interpretation)
7. Discussion (trade-offs, limitations, lessons learned)
8. Conclusion and Future Work   References

metric measurement protocol | only real measurements | implemented vs future work clearly separated.
